# WaterChemistry

Production › Operations › Water chemistry, Latest tab: one row per sampling point with status and the values that matter first.

- Head chips: "40 sampling points", "1 critical", "6 warnings"; Round (outlined) and Record sample (primary).
- Always show the safety sentence: "Nobody is alerted: critical values are shown here, not sent."
- P1 columns: Status, Temp., O₂, CO₂, pH; the rest in the drawer or a "More values" toggle.
- Each value is a value face: figure, then origin and age ("Sensor, 40 s ago", "Manual, 3 d ago, old"). A non-OK value shows glyph and number together and the bound it crossed ("limit 15.0").
- "no data" is a word; a point with no fish says why ("No fish in HA-R01, so no limits apply."); unmeasured points fold into "Not measured (8)".
