# Third-party software

Nothing from a package registry is shipped to the browser: the browser runs only this project's own TypeScript, compiled
into `static/js/`, and this project's stylesheets, one of them (`static/css/tw.css`) generated by the Tailwind CLI from its own
source (development tools below). The Python packages the server runs are in `requirements.txt` (pinned with hashes in
`docker/requirements.lock`); the MQTT ingest's crates are in `sensors-ingest/THIRD_PARTY` (checked against `Cargo.lock`,
licences gated by `sensors-ingest/deny.toml`) and the water-chemistry core's (the server only) in `chemcore/THIRD_PARTY`
(gated by `chemcore/deny.toml`).

## Python packages the server runs (`requirements.txt`, with what they pull in)

CI's licence gate (`.github/workflows/ci.yml`, job security) installs these and fails on any licence not allowed here, as
`pip-licenses` reads it: AGPL, SSPL, BUSL, a non-commercial licence or any new one fails until it is reviewed and added.
Allowed: `Apache-2.0`, `Apache-2.0 OR BSD-3-Clause`, `BSD-2-Clause`, `BSD-3-Clause`, `BSD License`, `LGPL-3.0-only`,
`MIT`, `MIT-0`, `PSF-2.0` (`MIT` since the linter below, ruff: the gate reads the test runner's packages too).

| Package | Licence (as pip-licenses reads it) | What it is used for |
|---|---|---|
| `Django` | BSD-3-Clause | The web framework |
| `asgiref` | BSD-3-Clause | Django's sync/async bridge |
| `babel` | BSD License (BSD-3-Clause) | The translation catalogs without GNU gettext (`core/catalogs.py`) |
| `cryptography` | Apache-2.0 OR BSD-3-Clause | AES-encrypted PDFs, for pypdf |
| `cffi`, `pycparser` | MIT-0, BSD-3-Clause | Pulled in by cryptography |

## Fonts served to the browser (`static/fonts/`)

The two typefaces of the design system (`docs/design/system/README.md`, Type), self-hosted as WOFF2 so that no page asks
another server for anything and the console works offline on site (`static/css/fonts.css`). Both are under the SIL Open
Font License 1.1, which allows commercial use, embedding and redistribution with the licence kept beside the files (it
is, in `static/fonts/OFL-*.txt`); only the fonts on their own may not be sold. Taken from Google Fonts (the Latin and
Latin Extended subsets) on 08.11.2026.

| Font | Licence | Copyright | Used for |
|---|---|---|---|
| Atkinson Hyperlegible Next (variable, 400–700) | OFL-1.1 (`static/fonts/OFL-atkinson-hyperlegible-next.txt`) | 2020-2024 The Atkinson Hyperlegible Next Project Authors | Every text read or entered (`--font-text`) |
| Bricolage Grotesque (600, optical size axis) | OFL-1.1 (`static/fonts/OFL-bricolage-grotesque.txt`) | 2022 The Bricolage Grotesque Project Authors | h1, h2 and the wordmark (`--font-display`) |


## Development-only tools (`package.json` devDependencies)

Used to build and test the browser code on a developer's machine or in CI; never served, never bundled.

| Package | Licence | What it is used for |
|---|---|---|
| `typescript` | Apache-2.0 | Compiles and type-checks `frontend/` |
| `@types/node` | MIT | Types of Node's test runner and assertions, for the TypeScript unit tests only (`tsconfig.test.json`) |
| `playwright-core` | Apache-2.0 | Drives the machine's own Chrome or Edge for the designer's browser test (`frontend/test/designer.browser.test.ts`); no browser is downloaded |
| `axe-core` | MPL-2.0 | Accessibility rules run in that browser test on the designer (serious and critical violations fail it) |
| `tailwindcss`, `@tailwindcss/cli` (4.3.3, pinned exactly) | MIT | Build `static/css/tw.css` from `frontend/tailwind.css` and the templates' `tw:` classes (`npm run build:css`, `scripts/tailwind.mjs`); only the built CSS is served, with Tailwind's MIT notice at its head. They pull in `lightningcss` (MPL-2.0, the CSS transformer, used unmodified), `@tailwindcss/oxide` and `@parcel/watcher` (MIT, native scanners, one prebuilt package per platform), `detect-libc` (Apache-2.0), `graceful-fs` and `picocolors` (ISC), `source-map-js` (BSD-3-Clause) and small MIT helpers (`enhanced-resolve`, `jiti`, `magic-string`, `micromatch`, `mri`, `tapable`, `@jridgewell/*`) |
